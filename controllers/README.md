# MERN Task Manager

## Features
- User Authentication
- JWT Authorization
- Protected Routes
- Task CRUD Operations

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Installation

### Backend
npm install
npm run dev

### Frontend
npm install
npm run dev

## Environment Variables

PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
